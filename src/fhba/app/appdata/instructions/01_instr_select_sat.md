## Select Analysis Year and Satellite Instrument
            
Select the `Year` and `Full Satellite Name` from the dropdowns and click `Next` to begin the analysis.

### Valid Date Ranges

Temporal coverage for the three VIIRS instruments onboard the Suomi-NPP, NOAA-20, and NOAA-21 satellites is listed in the table below:

| Satellite | Start Date | End Date | 
| --------- | ---------- | -------- |
| Suomi-NPP | 2015 NOV 24 | Ongoing |
| NOAA-20 | 2018 JAN 05 | Ongoing |
| NOAA-21 | 2023 FEB 10 | Ongoing |
