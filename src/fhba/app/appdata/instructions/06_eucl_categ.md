## Categorize Burned Pixels:

The dropdown to the right lists days with user-selected burned and unburned pixels. Select a date and press the `Load Analysis Date Image` and `Categorize Pixels` buttons to bring up the image and run the Euclidean categorization algorithm based on the user-selected burned and unburned pixels.

Review the preliminary burn mask, and if acceptable click the `Export Burnmask` button to save the output to a `.tif` file for subsequent processing.
