# Aggregate Burnmasks

Unlike the previous __[1. Download Granules](./download_granules.md)__, __[2. Process Granules](./process_granules.md)__, and  __[3. Classify Granules](./classify.md)__ sections, in the Aggregation section the user only selects a `Year` from the dropdown without selecting a `Satellite`. This is because the aggregation step combines the burnmasks from one or more satellites over the course of a given time period.

Once the year has been selected, click the __`Next`__ button.

## Aggregate Burnmasks from Different Satellites and Dates

The __Select Date Range__ dropdown calendar should be used to select a date range for the aggregation, and the user should use the checkboxes to select one or more satellites to include in the aggregation.

!!! info "Compare Different Satellite Combinations"
    The resultant filenames are based on the unique combination of satellites, so the user is free to generate aggregate burnmasks for different combinations of satellites, if desired.

The __`Aggregate Burnmasks`__ button will then combine all burnmasks in a cumulative fashion and a table will appear to display the cumulative burned area within each county.

Once all desired combinations and date ranges have been selected for Aggregation, click the __`Next`__ button.

## View Burnmasks

The two dropdowns allow the user to select the combination of satellites (utilizing satellite short name prefixes such as "VNP" for Suomi-NPP) as well as the start date for the aggrgation.

The display shows the resultant burn map along with the tally of acres burned within each county. The image is stored on the user's computer at the location listed at the bottom of the screen.
